# Employee Management System

## Project Description

Employee Management System is a Java-based application developed to manage employee records efficiently. The system allows users to add, update, delete, and view employee details using a MySQL database.

## Technologies Used

* Java
* Spring Boot / JDBC (use your actual technology)
* MySQL
* Maven
* GitHub

## Features

* Add employee details
* View employee records
* Update employee information
* Delete employee records
* Database integration with MySQL

## Database Setup

1. Open MySQL Workbench.
2. Run the SQL files available in the `sql` folder.
3. Configure database username and password in the application.

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA / Eclipse.
3. Update MySQL configuration.
4. Run the application.
